FDOx Registry

A registry for FAIR Digital Objects packaged with the FDOx Squirrel reference implementation: harvests FDO metadata published on Zenodo, bundles it into a DCAT catalogue anchored in CIDOC CRM, validates it with SHACL, and publishes a filter and SPARQL interface as a static site. This collection re-publishes the same CIDOC-CRM-anchored bundle (dist/fdo-registry-n4o.ttl) for the NFDI4Objects Knowledge Graph.
